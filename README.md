# Søvnlogg

Web-app for å følge søvn ved narkolepsi type 1. Leser FIT-filer fra Søvnlogg-appen på Garmin-klokke (og Apple Health, Fitbit, CSV), viser natten, dagbok, trender og en rapport til legen.

Alle data lagres bare lokalt på enheten (IndexedDB). Ingenting sendes til noen server.

Søvnstadiene er anslag fra puls og bevegelse og er ikke validert mot søvnmåling (PSG). Appen er ikke medisinsk utstyr.
